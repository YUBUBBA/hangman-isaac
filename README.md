Мой первый проектик на JS
где нужно угадать персонажа из The Binding of Isaac по буквам

## как играть
1. Открой файл `index.html` в браузере
2. Вводи буквы в появляющемся окне
3. Угадай имя персонажа до того, как закончатся жизни

## фишки проекта
- Случайный выбор персонажа
- 3 жизни
- Отображение угаданных букв
- Победа / проигрыш
- Возможность выйти из игры

## прогресс
- Функции в JavaScript
- Циклы и условия
- Массивы
- Работа со строками
- Логика игры

## иехнологии
- HTML
- JavaScript
